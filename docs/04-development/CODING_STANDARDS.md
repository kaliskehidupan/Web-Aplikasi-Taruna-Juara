# Coding Standards & Quality Matrix

## 1. General Principles

- **DRY (Don't Repeat Yourself)**: Extract reusable logic into utility functions or custom hooks.
- **KISS (Keep It Simple, Stupid)**: Avoid over-engineering data structures.
- **Clean Code**: Code should read like well-written prose. Variable names must be descriptive (`isHafalanCompleted` vs `flag`).

---

## 2. Naming Conventions

| Language / Context | Case Style | Example |
| --- | --- | --- |
| TypeScript Files | PascalCase for Components, camelCase for utils | `StudentCard.tsx`, `formatDate.ts` |
| CSS / Tailwind | kebab-case | `bg-warm-orange-500` |
| Python Files / Variables | snake_case | `santri_hafalan_progress.py` |
| Odoo Models | dot.notation | `tj.setoran.hafalan` |
