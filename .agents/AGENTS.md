# Taruna Juara Workspace Rules & Git Workflow

## Git Commit & Push Policy
1. **Target Branch for Development**: Always commit and push code changes to the **`saiful`** branch.
2. **Main Branch Protection**: Never push directly to `main`.
3. **Pull Request Workflow**: After committing and pushing changes to `saiful`, prepare/submit a Pull Request to merge `saiful` into `main`.
